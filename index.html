Rôle de Cloudflare

1
Tu tapes automate.viegratuitepourtous.tech dans ton navigateur
2
Cloudflare DNS résout le domaine → IP du VPS (masquée)
3
Cloudflare Proxy reçoit la requête, filtre les attaques
4
Forward vers Hostinger VPS :443 (HTTPS)
5
iptables Cloudron accepte le port 443
6
Nginx Cloudron lit le sous-domaine (automate) et route vers n8n
7
n8n traite la requête (workflow, webhook...)
8
Réponse remonte via Cloudflare → ton PC

⚠️ Point critique : SSH (port 2222) ne passe PAS par Cloudflare. C'est une connexion directe à l'IP du VPS. Si Cloudflare bloque une IP ou si le proxy est mal configuré, SSH n'est pas impacté. En revanche, si iptables Cloudron bloque le port 2222 (comme le 20 mai), SSH tombe — et là il faut la console VNC Hostinger.
